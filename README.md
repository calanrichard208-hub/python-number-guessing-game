# Python Number Guessing Game

## About the Project
An interactive number guessing game built using Python.

The player attempts to guess a randomly generated number with the help of hints.

## Features
- Three difficulty levels
- Interactive hints
- Attempt counter
- Top 5 leaderboard
- Player score tracking

## Technologies Used
- Python 3
- Random Module
- File Handling

## How to Run
1. Install Python 3.
2. Download this repository.
3. Open the project folder.
4. Run `python guessing_game.py`.
